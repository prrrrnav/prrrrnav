## 🚀 Featured Projects

### 🛰️ Semantic Segmentation on Satellite Imagery &nbsp;`Python` `TensorFlow` `Keras` `U-Net` `OpenCV` &nbsp;·&nbsp;*e&ICT IIT Kanpur, Project-Based Internship*
- Built an end-to-end semantic segmentation pipeline on Dubai satellite imagery using a **U-Net (TensorFlow/Keras)**, classifying every pixel into land-cover classes such as vegetation, water and buildings.
- Prepared the dataset from **8 image tiles** by consolidating images and pixel-wise masks into filename-matched pairs, loaded through a TensorFlow input pipeline.
- Trained the encoder–decoder model, compared predictions with ground-truth masks on unseen images, and saved the trained model for reuse.

### 🚁 NIDAR Drone Navigation — Team Lead &nbsp;`Python` `YOLO` `OpenCV` `GPS` &nbsp;·&nbsp;*Aug 2025 – Dec 2025*
- Led a **4-member CSE team** through 6 sprints, guiding integration and collaboration across the vision and GPS modules.
- Applied **YOLO** for real-time computer vision and integrated it with GPS modules in a Python/OpenCV pipeline, sustaining autonomous missions across **30 acres** with zero mission-ending faults.
- Designed the system architecture and presented the solution, **securing ₹4.5L in funding**, and ranked **Top 20 among 500+ teams**.

### 🧠 LeetAlly: AI Interview Practice Extension &nbsp;`Chrome Extension` `FastAPI` `Python` `AI` &nbsp;·&nbsp;[**Live on Chrome Web Store**](https://chromewebstore.google.com/detail/leetally-leetcode-intervi/kbmamkkghfaagfplfdgpdocmgakhjmlo)
- Built and published a Chrome extension with a **FastAPI backend** that runs an AI interviewer for DSA, behavioural, LLD and HLD practice, with concise feedback after every round.
- Added DSA pattern recognition, solved-problem and streak tracking, and company-wise question sheets.

### 🔐 Stateless Auth & Rate-Limited API Service &nbsp;`Node.js` `Express.js` `Redis` `PostgreSQL` `Docker` `AWS EC2` `JWT` &nbsp;·&nbsp;*Oct 2025 – Feb 2026*
- Designed a stateless, horizontally scalable API gateway, separating session state (**Redis**) from persistent storage (**PostgreSQL**) to handle concurrent load.
- **Improved throughput by ~20%** and cut latency by ~15–20ms using JWT authentication and Redis-backed rate limiting.
- Containerized the API with Docker and deployed it on AWS EC2 through a **GitHub Actions CI/CD** pipeline.

### 📄 Applicant Tracking System (ATS) Platform &nbsp;`FastAPI` `Python` `OpenAI API` `MongoDB` `Docker` `JWT` &nbsp;·&nbsp;*Jun 2025 – Sep 2025*
